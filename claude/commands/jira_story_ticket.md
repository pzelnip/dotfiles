description: Create a JIRA ticket description for changes on current branch
---

Create a clear, concise JIRA ticket description for the the changes on the current branch (diffed against `main`).  Include:

- a high level description of the change
- an "Acceptance Criteria" section
- an "Additional Info" section containing any extra useful info about the change (be concise)

Make each section a level 3 heading.

Format this as markdown and save to JIRA_TICKET.md and overwrite that file if it already exists.
